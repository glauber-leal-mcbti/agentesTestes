## Workflow

### Step 1: Initial Variables

1. Ask the user which MATLAB version should be used. Available versions: R2024b, R2025a, R2025b.
2. Ask the user for the `.prj` project path and store it as `{CAMINHO_PRJ}`.
3. Ask the user which `.m` script should be tested and store it as `{CAMINHO_SCRIPT}`.
4. Ask the user for the requirements file associated with the script and store it as `{CAMINHO_REQUISITOS}`.
5. Ask the user where test files should be saved and store it as `{CAMINHO_TESTE}`.
6. Retain this information for subsequent steps.

### Step 2: MATLAB Initialization

1. Start MATLAB using the requested version via `bash_tool`.

### Step 3: MATLAB Project Analysis

1. Use `view` on `{CAMINHO_PRJ}` to identify:

   * Files included in the project
   * Configured paths
   * Dependencies

2. Use `view` on `{CAMINHO_REQUISITOS}` to identify:

   * Number of requirements to be tested
   * Name of each requirement
   * Characteristics of each requirement
   * Expected inputs for each requirement
   * Expected outputs for each requirement

3. Use `view` on `{CAMINHO_SCRIPT}` to identify:

   * Script inputs
   * Script outputs

### Step 4: Test File Creation (Parallel)

Create multiple agents to generate tests simultaneously.

For each requirement identified in Step 3, spawn an independent agent.

Spawn agents using the results from the Step 3 analysis:

* `script_path`: `{CAMINHO_SCRIPT}`
* `script_functions`: functions identified in Step 3
* `script_inputs`: inputs identified in Step 3
* `script_outputs`: outputs identified in Step 3
* `requirement_name`: requirement name
* `requirement_inputs`: expected requirement inputs
* `requirement_outputs`: expected requirement outputs

**Important:** Start all agents simultaneously in a single call to enable parallel execution. Do not wait for one agent to finish before starting the next.

Wait until all agents have completed before proceeding to Step 5.

### Step 5: Validate Test Execution

For each test file created in Step 4, spawn a test-runner agent.

Read the file `agents/test-runner.md` using `view` and start all agents simultaneously, passing:

* `test_file`: path to the generated test file
* `project_path`: `{CAMINHO_PRJ}`
* `matlab_version`: `{VERSAO_MATLAB}`

Wait for all agents to complete.

If any test returns an `error`:

1. Present the error to the user.
2. Ask whether they would like to fix the test file and try again.
3. Use Step 5 again to verify that the issue has been resolved.
